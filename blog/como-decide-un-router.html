Cómo decide un router el siguiente salto

EnrutamientoPaso 5 de la ruta de estudio· 5 min de lectura

Un router recibe un paquete y tiene que decidir, en microsegundos, por dónde mandarlo. No adivina: consulta su tabla de enrutamiento y aplica una regla muy concreta.

Una decisión por destino

El router mira la IP de destino del paquete y la busca en su tabla. Cada ruta dice hacia qué red aplica, por qué interfaz sale y, cuando hace falta, cuál es el siguiente salto: la IP del próximo router en el camino.

Gana el prefijo más específico

Imagina que un router tiene estas rutas:

DestinoSiguiente salto
10.42.8.0/24Router B
10.42.0.0/16Router A
0.0.0.0/0Salida predeterminada

Llega un paquete para 10.42.8.20. Las tres rutas coinciden, pero gana 10.42.8.0/24 porque fija más bits del destino. A esto se le llama longest prefix match, y es la regla que usan todos los routers.

La ruta 0.0.0.0/0 es la ruta predeterminada: coincide con todo, pero como tiene el prefijo más corto, solo se usa cuando ninguna otra coincide.

Lee una tabla real

# Windows
route print -4

# Linux
ip route

# Router Cisco
show ip route

Busca la ruta predeterminada y observa a qué interfaz o puerta de enlace apunta. En un router Cisco, las letras al inicio de cada línea te dicen de dónde salió la ruta: C conectada, S estática, O OSPF.

Prueba otra dirección

Con la tabla del ejemplo, ¿hacia dónde se enviaría un paquete para 10.42.9.20?

Ver respuesta

Router A. No coincide con 10.42.8.0/24 (el tercer octeto es 9), pero sí con 10.42.0.0/16, que es más específica que la ruta predeterminada.
