Fundamentos de redes

Ruta de estudio

Seis lecturas en orden para entender cómo se conectan dos equipos y qué revisar cuando esa conexión falla. Cada etapa trae una práctica para hacer en tu propio equipo.

  1. 01
    Fundamentos

    El modelo OSI explicado con lo que pasa al abrir una página web

    Las 7 capas del modelo OSI explicadas siguiendo lo que pasa cuando abres una página: qué hace cada capa, sus PDU, protocolos y equipos.

    Práctica · Ubica en qué capa trabaja cada equipo de tu red de casa.

  2. 02
    Fundamentos

    Direcciones IP y subredes desde cero

    Aprende a leer un prefijo como /24 y a reconocer cuándo dos direcciones están en la misma subred.

    Práctica · Compara dos direcciones IPv4 con el mismo prefijo.

  3. 03
    Subnetting

    VLSM paso a paso: reparte una /24 sin desperdiciar IPs

    Un ejercicio completo de VLSM: cuatro redes de distinto tamaño y dos enlaces WAN dentro de 192.168.10.0/24, resuelto paso a paso.

    Práctica · Reparte 172.16.0.0/24 entre tres LAN y tres enlaces WAN.

  4. 04
    DNS

    ¿Qué pasa cuando escribes un dominio?

    Acompaña una consulta DNS desde tu equipo hasta el servidor que conoce la respuesta: resolvedor, raíz, autoritativo y registros.

    Práctica · Consulta los registros A, AAAA y MX de un dominio.

  5. 05
    Enrutamiento

    Cómo decide un router el siguiente salto

    Lee una tabla de rutas y descubre qué ocurre cuando varias entradas coinciden con el mismo destino.

    Práctica · Lee una tabla de rutas y elige el siguiente salto.

  6. 06
    Diagnóstico

    Tu equipo tiene Wi-Fi, pero la web no carga

    Un recorrido práctico para separar problemas de configuración, resolución DNS y conexión al sitio.

    Práctica · Usa la guía para revisar la conexión desde tu equipo.
