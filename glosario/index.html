ARP
Protocolo usado en redes IPv4 como Ethernet para resolver la MAC de un vecino del enlace local. Para un destino remoto se resuelve la del siguiente salto; IPv6 utiliza Neighbor Discovery.Direcciones IP y subredes desde cero →
CNAME
Registro DNS que indica que un nombre es alias de otro, por ejemplo www apuntando a un servicio de hosting.¿Qué pasa cuando escribes un dominio? →
DHCP
Protocolo que entrega automáticamente a un equipo su IP, máscara, puerta de enlace y servidores DNS.Tu equipo tiene Wi-Fi, pero la web no carga →
Dirección IP
Identificador numérico de una interfaz en una red. Los paquetes llevan una IP de origen y una de destino.Direcciones IP y subredes desde cero →
Dirección MAC
Dirección de enlace, habitualmente de 48 bits en Ethernet y Wi-Fi. Puede configurarse o aleatorizarse; no debe tratarse como identidad permanente de una persona o equipo.El modelo OSI explicado con lo que pasa al abrir una página web →
DNS
Sistema distribuido que traduce nombres de dominio en información como direcciones IP o servidores de correo.¿Qué pasa cuando escribes un dominio? →
Encapsulación
Proceso de transportar datos de un protocolo dentro de la unidad de otro. Puede añadir encabezados y campos finales, como en Ethernet; no todas las capas OSI añaden un encabezado independiente.El modelo OSI explicado con lo que pasa al abrir una página web →
Máscara de subred
Forma decimal del prefijo: indica qué parte de la IP es red y qué parte es host. /24 = 255.255.255.0.Direcciones IP y subredes desde cero →
MX
Registro DNS que indica qué servidores reciben el correo de un dominio y en qué orden de prioridad.¿Qué pasa cuando escribes un dominio? →
PDU
Unidad de datos de cada capa: bits, trama, paquete, segmento o datos.El modelo OSI explicado con lo que pasa al abrir una página web →
Prefijo de red
Bits iniciales de una dirección que identifican la red. La notación /24 indica un prefijo de 24 bits.Direcciones IP y subredes desde cero →
Puerta de enlace
Siguiente salto usado por una ruta predeterminada cuando no existe una ruta más específica aplicable al destino.Cómo decide un router el siguiente salto →
Ruta predeterminada
Ruta que coincide con cualquier destino: 0.0.0.0/0 en IPv4 o ::/0 en IPv6. Se usa cuando no coincide una ruta instalada más específica.Cómo decide un router el siguiente salto →
Siguiente salto
Siguiente router al que se reenvía un paquete según la ruta elegida.Cómo decide un router el siguiente salto →
TCP
Protocolo de transporte orientado a conexión que ofrece un flujo fiable y ordenado de bytes mediante secuenciación y retransmisiones. Una conexión puede fallar sin completar la transferencia.El modelo OSI explicado con lo que pasa al abrir una página web →
TTL en DNS
Valor en segundos de un registro de recursos que limita su permanencia en caché. El TTL restante disminuye mientras el registro está almacenado.¿Qué pasa cuando escribes un dominio? →
UDP
Protocolo de transporte de datagramas sin conexión que no garantiza entrega ni orden. Su mecanismo es reducido, pero no es siempre más rápido que TCP. La aplicación puede añadir fiabilidad.El modelo OSI explicado con lo que pasa al abrir una página web →
VLAN
Red local virtual: divide un switch en varios dominios de difusión separados, como si fueran switches distintos.El modelo OSI explicado con lo que pasa al abrir una página web →
VLSM
Técnica para dividir una red en subredes de distinto tamaño, cada una con la máscara que necesita.VLSM paso a paso: reparte una /24 sin desperdiciar IPs →
